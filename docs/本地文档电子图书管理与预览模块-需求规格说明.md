## 1. 引言

### 1.1 目的

本文档定义"本地文档/电子图书管理与预览模块"的完整功能需求、非功能需求及系统设计规范，供产品、研发、测试团队作为开发基准文档使用。

### 1.2 范围

该模块是本地媒体管理系统（家庭服务器场景）的子系统，聚焦于**本地文档与电子书的管理、浏览、在线阅读与下载**，不涉及视频/音频媒体管理。

### 1.3 背景

用户在本地 NAS、家庭服务器或个人 PC 上存储了大量文档（PDF、Word、Markdown 等）及电子书（EPUB、MOBI 等），现有方案（如直接用文件浏览器或第三方客户端）存在以下痛点：

- 缺乏统一的 Web 端在线阅读体验
- 无法按书名、作者、标签等元数据快速检索
- 批量下载操作繁琐
- 隐私数据暴露风险（依赖云服务）

本模块提供**纯本地化、私有化部署**的解决方案，保障隐私安全的同时提供媒体库级别的使用体验。

### 1.4 参考文档

| 文档 | 说明 |
|------|------|
| 本地照片管理系统需求规格 | 同一系统的姊妹模块 |
| EPUB 3.0 规范 | 电子书格式标准 |

## 2. 系统概述

### 2.1 系统定位

```
用户通过浏览器（局域网或 localhost）访问本地部署的 Web 服务
→ 扫描指定目录 → 建立元数据索引
→ 提供目录浏览、格式预览、全文搜索、下载等功能
```

### 2.2 核心价值主张

| 维度 | 描述 |
|------|------|
| 隐私安全 | 完全本地化，无需上传云端，数据不离开设备 |
| 统一入口 | 多目录、多格式统一管理，一个界面覆盖所有文档 |
| 在线可读 | 无需下载即可阅读 PDF、EPUB、TXT、Markdown |
| 智能索引 | 自动提取作者、书名、标签、摘要等元数据 |
| 快速检索 | 支持全文搜索与多维度筛选 |
| 跨端访问 | 局域网内任意设备（手机、平板、电脑）均可访问 |

## 3. 用户角色与场景

### 3.1 用户角色

| 角色 | 描述 | 权限 |
|------|------|------|
| 管理员（Admin） | 家庭服务器拥有者，负责配置 | 全部功能 + 配置管理 |
| 普通用户（User） | 家庭成员或授权访客 | 浏览 + 阅读 + 下载 |
| 访客（Guest） | 临时访客，受限访问 | 仅浏览 + 阅读（不可下载） |

### 3.2 核心使用场景

**场景 1：发现并阅读一本电子书**
> 用户打开浏览器 → 进入"图书馆"界面 → 在搜索框输入书名关键词 → 找到目标 EPUB 文件 → 点击"在线阅读"→ 在浏览器内分章节翻页阅读

**场景 2：批量下载资料**
> 用户进入某技术文档目录 → 勾选多个 PDF 文件 → 点击"批量下载"→ 系统打包为 ZIP 文件并推送下载

**场景 3：查找某作者的所有作品**
> 用户点击左侧"作者"分类 → 选择作者名 → 看到该作者名下所有文档的列表

**场景 4：管理员添加新扫描目录**
> 管理员进入设置页面 → 添加新的本地路径 → 触发扫描 → 新文件被索引并出现在库中

## 4. 功能需求

### 4.1 目录扫描与索引

#### 4.1.1 扫描配置

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| SCAN-01 | 管理员可添加 1~N 个本地目录路径作为扫描源 | P0 |
| SCAN-02 | 支持递归扫描子目录（默认开启，可关闭） | P0 |
| SCAN-03 | 支持按路径或通配符配置排除规则（如排除 `node_modules/**`） | P1 |
| SCAN-04 | 支持手动触发扫描和定时自动扫描（Cron 配置） | P0 |
| SCAN-05 | 扫描进度实时显示（当前文件、总进度、已扫描数量） | P1 |
| SCAN-06 | 增量扫描：仅处理新增/修改的文件，不重复全量扫描 | P1 |
| SCAN-07 | 扫描日志可查看，记录新增/更新/跳过/失败的文件 | P2 |

#### 4.1.2 元数据提取

系统在扫描时自动从文件内容及文件属性中提取以下元数据：

| 字段 | 来源 | 说明 |
|------|------|------|
| 标题 | 文件名 / 文档内嵌元数据 | 优先读取内嵌，其次用文件名 |
| 作者 | 文档内嵌元数据 | PDF Author、EPUB creator |
| 出版社 | 文档内嵌元数据 | EPUB publisher |
| 出版年份 | 文档内嵌元数据 | - |
| 文件格式 | 文件扩展名 + MIME 检测 | 防止扩展名伪装 |
| 文件大小 | 文件系统 | 字节 |
| 修改时间 | 文件系统 | mtime |
| 语言 | 文档内嵌 / 自动检测 | EPUB lang 或 CLD3 推测 |
| 标签/分类 | 文档内嵌 / 用户手动 | - |
| 摘要/简介 | 文档内嵌 | PDF Subject、EPUB description |
| 封面图片 | 文档内嵌 | EPUB cover、PDF 首页截图 |
| 页数 | 解析文档 | - |

#### 4.1.3 格式识别规则

- **扩展名优先识别**：`.pdf`, `.epub`, `.mobi`, `.txt`, `.md`, `.docx`, `.xlsx`, `.pptx`, `.csv`, `.html`
- **MIME 类型兜底**：当扩展名缺失或与内容不符时，读取文件头字节（Magic Number）进行确认
- **忽略规则**：文件大小 < 1KB 的文件默认不索引；隐藏文件（`.`开头）默认不索引

### 4.3 在线阅读预览

这是模块的核心功能，针对不同格式提供对应的阅读体验。

#### 4.3.1 各格式阅读方案

| 格式 | 渲染方案 | 功能要求 |
|------|----------|----------|
| **PDF** | PDF.js（Mozilla 开源） | 分页翻页、缩放、页码跳转、全屏模式 |
| **EPUB** | Epub.js | 分章节导航、字体大小调节、背景色切换、进度记忆 |
| **TXT / MD** | 前端直接渲染 | Markdown 渲染为 HTML，代码高亮，支持深色模式 |
| **HTML** | iframe 沙盒嵌入 | 限制 JS 执行（sandbox 属性），防止 XSS |
| **DOCX / XLSX** | 服务端转 HTML 或 PDF 后渲染 | LibreOffice 无头转换 |
| **图片类（JPG/PNG）** | `<img>` 直接展示 | 支持缩放、旋转 |
| **CSV** | 前端解析为表格 | 支持滚动、列宽调整 |

#### 4.3.2 阅读器通用功能

| 需求 ID | 描述 | 优先级 |
|---------|------|--------|
| READ-01 | 阅读进度自动保存（基于 localStorage 或服务端用户记录） | P0 |
| READ-02 | 目录/大纲面板（PDF 书签、EPUB ToC） | P0 |
| READ-03 | 全屏阅读模式 | P1 |
| READ-04 | 字体大小调节（TXT/MD/EPUB） | P1 |
| READ-05 | 主题切换：亮白、护眼米黄、暗黑三种 | P1 |
| READ-06 | 阅读器内快速搜索（Ctrl+F / 移动端工具栏） | P1 |
| READ-07 | 页面/位置分享：生成包含定位信息的链接 | P2 |
| READ-08 | 划词高亮与注释（仅 EPUB/TXT/MD） | P3 |

#### 4.3.3 性能要求

- PDF 首页渲染时间 ≤ 2 秒（局域网 100Mbps 环境，文件 ≤ 10MB）
- EPUB 首章节加载 ≤ 1 秒
- 大文件（> 50MB）采用流式分页加载，避免一次性传输

## 5. 非功能需求

### 5.1 性能

| 指标 | 要求 |
|------|------|
| 目录浏览响应时间 | ≤ 300ms（局域网，1000 文件以内） |
| 搜索响应时间 | ≤ 500ms（100,000 文件索引规模） |
| PDF 首页渲染 | ≤ 2s（10MB 文件，局域网） |
| 并发用户数 | ≥ 10 个并发用户同时正常使用 |
| 扫描吞吐量 | ≥ 500 文件/分钟（SSD 环境） |
| 系统内存占用 | 空闲时 ≤ 200MB，峰值 ≤ 512MB |

### 5.2 可靠性

- 服务崩溃后，索引数据库不丢失
- 支持热重启（服务重启不影响进行中的下载任务）
- SQLite 数据库定期备份（每日自动，保留 7 天）

### 5.3 可用性

- 支持 24/7 后台运行（作为系统服务/Docker 容器）
- 提供健康检查接口 `GET /health`
- 操作界面适配移动端（响应式布局）
- 支持键盘导航和基础无障碍访问（ARIA 标签）

### 5.4 可维护性

- 后端采用 RESTful API 设计，前后端分离
- 配置项集中在单一配置文件（`config.yaml`）
- 支持 Docker Compose 一键部署
- 提供 Swagger/OpenAPI 文档

### 5.5 兼容性

| 环境 | 最低要求 |
|------|----------|
| 浏览器 | Chrome 90+, Firefox 90+, Safari 14+, Edge 90+ |
| 服务端 OS | Linux (Ubuntu 20.04+), macOS 12+, Windows 10+ |
| Node.js | 18.x LTS 或以上（若后端选 Node）|
| Python | 3.10 或以上（若后端选 Python）|

### 6.2 格式转换服务

DOCX / XLSX / PPTX / MOBI 等格式的在线预览通过以下方式实现：

1. **LibreOffice Headless**：将 Office 格式转换为 PDF，再由 PDF.js 渲染（服务端完成）
2. **转换缓存**：转换结果缓存到磁盘，避免重复转换（TTL 30 天或源文件变更触发失效）

### 7.2 核心数据流

```
用户请求浏览 /api/files?dir=xxx
    ↓
后端鉴权（JWT/Session）
    ↓
查询 SQLite 索引（不直接读取文件系统）
    ↓
返回文件列表（文件 ID + 元数据，不含真实路径）
    ↓
前端渲染卡片列表

用户点击"在线阅读"
    ↓
请求 /api/files/{id}/stream
    ↓
后端根据 ID 查找真实路径 → 流式读取 → 分块传输
    ↓
浏览器 PDF.js / Epub.js 渲染
```

## 8. 接口设计（API 规范）

### 8.1 文件列表

```
GET /api/v1/files
Query Params:
  - dir: string        # 目录 ID 或路径别名
  - format: string     # 格式过滤，逗号分隔（pdf,epub）
  - sort: string       # name|size|mtime|added_at
  - order: asc|desc
  - page: int
  - per_page: int（默认 50，最大 200）
  - keyword: string    # 搜索关键词

Response 200:
{
  "total": 320,
  "page": 1,
  "data": [
    {
      "id": "f_abc123",
      "title": "深入理解计算机系统",
      "author": "Randal E. Bryant",
      "format": "pdf",
      "size": 15728640,
      "mtime": "2024-03-01T10:00:00Z",
      "cover_url": "/api/v1/files/f_abc123/cover",
      "tags": ["计算机", "编程"],
      "pages": 784
    }
  ]
}
```

### 8.2 文件预览流

```
GET /api/v1/files/{id}/stream
Headers:
  - Range: bytes=0-1048576（支持断点续传）
  - Authorization: Bearer {token}

Response 200 / 206:
  Content-Type: application/pdf（或对应 MIME）
  Content-Length: ...
  Accept-Ranges: bytes
  （文件字节流）
```

### 8.3 文件下载

## 11. 错误处理规范

| HTTP 状态码 | 场景 | 前端处理 |
|-------------|------|----------|
| 401 | 未登录或 Token 过期 | 跳转登录页 |
| 403 | 无权限访问该文件 | 提示"无访问权限" |
| 404 | 文件 ID 不存在（源文件已删除） | 提示"文件不存在，可能已被移动或删除" |
| 413 | 下载 ZIP 超过服务器限制 | 提示"文件过大，请减少批量数量" |
| 500 | 服务端内部错误 | 提示"系统繁忙，请稍后重试" + 错误 ID |
| 503 | 格式转换服务不可用 | 提示"预览服务暂不可用，建议直接下载" |

## 13. 约束与假设

1. **只读文档目录**：系统只读访问文档目录，不修改、删除、移动原始文件
2. **局域网优先**：主要面向局域网访问，互联网远程访问需用户自行配置端口映射或 VPN
3. **文件数量规模**：单次部署合理支持范围为 100 ~ 500,000 个文件
4. **无 DRM 支持**：本模块不处理任何受 DRM（数字版权管理）保护的商业电子书，仅管理用户自有文件
5. **MOBI 转换依赖 Calibre**：MOBI 格式转换需系统安装 Calibre，若未安装则跳过该格式
6. **LibreOffice 可选**：若不安装 LibreOffice，DOCX/XLSX/PPTX 将仅支持下载，不支持在线预览
