构建一个面向个人用户的**本地音乐归纳收录与播放一体化平台**，参考 Plex Media Server 的音乐管理模式，实现本地磁盘目录扫描 → 自动归类入库 → 专辑/艺人/标签管理 → 流畅播放体验的完整闭环。

### 1. 目标

- 自动扫描指定磁盘目录，识别并入库所有音频文件
- 以专辑、艺人、流派等维度对音乐进行结构化组织
- 支持收藏夹、播放列表等个性化管理功能
- 提供功能完整的本地音乐播放器（含均衡器、队列管理等）
- 支持元数据的浏览、展示与手动编辑

### 2. 典型使用场景

**场景 A — 初次入库**  
用户首次打开应用，添加 D:\Music、E:\FLAC 等多个目录作为媒体库，系统自动扫描并将所有音频文件分类归档为专辑和艺人列表。

**场景 B — 日常浏览**  
用户打开资料库，按专辑视图浏览，找到某张专辑后查看音轨列表，点击播放。

**场景 C — 整理收藏**  
用户发现部分文件的专辑/艺人信息标注为"Unknown"，通过元数据编辑器手动修正，并为专辑评分、收藏。

**场景 D — 创建播放列表**  
用户将不同专辑的歌曲拖拽组合成"下午工作"播放列表，并设置随机播放模式。

**场景 E — 新文件入库**  
用户下载了新专辑并放入已监控目录，系统自动检测到文件变化并将新文件追加入库，无需手动重新扫描全库。

## 3. 功能需求
### 3.1 本地磁盘扫描与入库

#### 3.1.1 媒体库目录配置

| 需求ID | 描述 | 优先级 |
|--------|------|--------|
| SCN-001 | 用户可添加一个或多个本地目录作为媒体库路径 | P0 |
| SCN-002 | 支持排除特定子目录（如 Temp、Download 临时目录） | P1 |
| SCN-003 | 媒体库配置持久化保存，重启后自动加载 | P0 |
| SCN-004 | 支持为不同媒体库设置别名（如"古典音乐"、"流行收藏"） | P2 |

#### 3.1.2 扫描行为

| 需求ID | 描述 | 优先级 |
|--------|------|--------|
| SCN-010 | 支持全量扫描：遍历所有配置目录下的音频文件 | P0 |
| SCN-011 | 支持增量扫描：仅处理自上次扫描后新增/修改的文件 | P1 |
| SCN-012 | 支持文件系统监听（FSWatch），当目录内有文件变化时自动触发增量扫描 | P1 |
| SCN-013 | 支持的音频格式：MP3、FLAC、AAC（m4a）、OGG、WAV、AIFF、APE、WMA | P0 |
| SCN-014 | 扫描时显示进度（已扫描文件数 / 总文件数、当前处理路径） | P1 |
| SCN-015 | 扫描结束后输出入库报告（新增数量、更新数量、失败文件列表） | P1 |
| SCN-016 | 扫描失败文件（无法解析、格式不支持等）单独记录，不阻断整体扫描流程 | P0 |

#### 3.1.2 元数据提取规则

系统从以下来源按优先级提取元数据：

1) **音频文件内嵌标签**（ID3v2 / Vorbis Comment / APEv2 等）— 最高优先级
2) **文件名模式解析**（`艺人名 - 曲目名.mp3` 等常见命名规则）— 回退方案
3) **目录结构推断**（`/艺人名/专辑名/曲目名.mp3` 目录层级）— 最低优先级

| 字段 | 说明 |
|------|------|
| 曲名（Title） | 必填，缺失时使用文件名（去扩展名） |
| 艺人（Artist） | 支持多艺人（分隔符：`;` 或 `/`） |
| 专辑艺人（Album Artist） | 用于合辑归类 |
| 专辑名（Album） | 缺失时归入 `[Unknown Album]` |
| 音轨编号（Track No.） | 用于专辑内排序 |
| 年份（Year） | 可选 |
| 流派（Genre） | 可选，支持多值 |
| 封面图（Artwork） | 内嵌封面 > 同目录 cover.jpg/folder.jpg > 无封面（显示占位图） |
| 时长（Duration） | 从音频流解析，非标签 |
| 比特率（Bitrate） | 从音频流解析 |
| 采样率（Sample Rate） | 从音频流解析 |
