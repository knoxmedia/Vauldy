## 1. 项目概述

### 1.1 项目背景

随着个人数字资产（照片、截图、设计稿等）的持续增长，用户在本地设备上积攒了海量图片文件，亟需一套**轻量、高效、体验友好**的本地图片管理工具，能够在本地完成浏览、检索和管理，同时支持在线环境下的预览与分发。

### 1.2 产品定位

一款面向个人用户和家庭场景的**本地图片管理与在线预览下载系统**，核心提供三大浏览维度（时光轴、智能分类、最近上传）+ 全屏沉浸查看体验，让用户像翻阅相册一样浏览本地图片。

### 1.3 目标用户

| 用户类型 | 典型场景 |
|---------|---------|
| 摄影爱好者 | 整理和回顾多年拍摄的照片，按时间线快速定位某次旅行的照片 |
| 设计师 / 创作者 | 管理本地素材库，按分类（截图、插画、参考图等）快速检索 |
| 普通家庭用户 | 浏览家庭照片，按时间或人物分类查看，下载到本地或分享 |
| 小型团队 | 共享本地图片素材，在线预览后下载需要的资源 |

### 1.4 核心目标

- **浏览效率**：用户可在 3 秒内定位到任意时间点的照片
- **分类准确率**：智能分类准确率 ≥ 90%
- **加载性能**：1000 张照片缩略图列表首次渲染 ≤ 1.5 秒
- **全屏体验**：全屏模式翻页延迟 ≤ 200ms

## 2. 用户角色与使用场景

### 2.1 用户角色

| 角色 | 权限范围 | 说明 |
|-----|---------|------|
| 访客（Guest） | 仅浏览、预览 | 无需登录，可浏览公开分享的图片 |
| 普通用户（User） | 浏览、分类、搜索、下载 | 系统默认角色，管理自己的图片库 |
| 管理员（Admin） | 全部权限 + 系统配置 | 管理用户、存储策略、系统参数 |

### 2.2 核心使用场景

| 场景编号 | 场景名称 | 描述 |
|---------|---------|------|
| SC-01 | 按时光轴回顾 | 用户进入时光轴视图，滑动时间轴定位到"2024年春节"，查看该时段的所有照片 |
| SC-02 | 智能分类浏览 | 用户切换到分类视图，点击"人物"分类，系统展示所有含人物的照片 |
| SC-03 | 查看最新图片 | 用户进入"最近上传"页面，以瀑布流形式浏览最近 7 天新增的图片 |
| SC-04 | 全屏沉浸浏览 | 用户点击某张照片进入全屏模式，左右滑动或按键盘方向键翻看相邻照片 |
| SC-05 | 下载单张/批量 | 用户选中若干照片，点击下载按钮，系统打包为 ZIP 并提供下载 |
| SC-06 | 关键词搜索 | 用户在搜索框输入"海滩"，系统按文件名、标签、AI 识别内容进行模糊匹配 |

### 3.1 时光轴浏览

#### 3.1.1 功能描述

以**时间为维度**组织所有本地图片，沿一条纵向或横向的时间轴排列。参照主流相册应用的交互范式，用户可在时间轴上快速定位到特定年/月/日，查看该时段的照片缩略图。

#### 3.1.2 详细需求

| 编号 | 需求项 | 详细描述 | 优先级 |
|------|-------|---------|--------|
| TL-01 | 时间轴渲染 | 以**年-月-日**为三级粒度渲染时间轴，默认展开到月级别 | P0 |
| TL-02 | 快速跳转 | 提供年份选择器，用户可快速跳转到指定年份 | P0 |
| TL-03 | 缩略图展示 | 每个日期节点下以**网格布局**展示当天所有照片缩略图（默认 4 列） | P0 |
| TL-04 | 日期标记 | 有照片的日期显示**圆点/高亮标记**，无照片日期灰显或隐藏 | P1 |
| TL-05 | 滚动加载 | 时间轴支持无限滚动，向下滚动自动加载更早日期的照片（分页 50 张/批） | P0 |
| TL-06 | 空状态 | 某日期无照片时显示占位图标与文案："这一天还没有照片" | P1 |
| TL-07 | EXIF 日期优先 | 图片排序优先读取 EXIF 拍摄日期，若无则回退到文件创建/修改日期 | P0 |
| TL-08 | 照片计数 | 每个日期分组标题旁显示该日照片数量，如"2024-03-15 · 23 张" | P1 |

#### 3.1.3 交互流程

```
[进入时光轴] → [默认定位到最近有照片的月份]
    → [用户上下滑动浏览] → [自动加载更早日期的照片]
    → [点击年份标签] → [弹出年份选择器]
    → [选择 2023 年] → [时间轴跳转至 2023 年 1 月]
    → [展开某月] → [显示该月下每日分组]
    → [点击某张缩略图] → [进入全屏查看模式]
```

#### 3.1.4 参考 UI 风格（基于参考图片）

- 时间轴主体位于左侧或顶部，年份用大字体突出显示
- 月份以卡片/分隔线形式出现，不同月份间有视觉分隔
- 缩略图采用**圆角矩形、均匀间距**的网格布局
- 整体配色以浅色/深色主题均可，强调图片本身色彩

### 3.2 智能分类浏览

#### 3.2.1 功能描述

系统通过 AI 图像识别模型对本地图片进行自动分类，用户可在分类视图下按类别浏览照片，而无需手动创建文件夹或标签。

#### 3.2.2 分类维度

| 分类维度 | 子类别示例 | 识别方式 |
|---------|-----------|---------|
| 内容类别 | 人物、风景、美食、动物、建筑、文档/截图、夜景、自拍 | AI 图像识别 |
| 颜色主调 | 暖色系、冷色系、黑白、高饱和度 | 色彩直方图分析 |
| 图片来源 | 相机拍摄、手机截图、下载保存、设计软件导出 | 文件元数据分析 |
| 文件类型 | JPEG、PNG、GIF、RAW、HEIC、WebP、BMP、SVG | 文件扩展名 + MIME 检测 |

#### 3.2.3 详细需求

| 编号 | 需求项 | 详细描述 | 优先级 |
|------|-------|---------|--------|
| SC-01 | 分类标签栏 | 顶部/侧边展示分类标签（带图标），点击切换到对应分类 | P0 |
| SC-02 | AI 自动分类 | 使用本地或云端 AI 模型对图片内容进行识别并打上分类标签 | P0 |
| SC-03 | 手动修正 | 用户可对 AI 分类结果进行修正（更改分类/添加标签） | P1 |
| SC-04 | 多标签支持 | 一张照片可同时属于多个分类（如既是"人物"又是"风景"） | P1 |
| SC-05 | 分类计数 | 每个分类标签旁显示该分类图片数量 | P1 |
| SC-06 | 瀑布流布局 | 分类浏览视图采用**瀑布流（Masonry）**布局，自适应图片宽高比 | P0 |
| SC-07 | 分类进度 | 显示 AI 分类任务进度，支持断点续扫 | P2 |
| SC-08 | 自定义分类 | 用户可创建自定义分类并手动添加照片 | P2 |

#### 3.2.4 AI 模型要求

| 指标 | 要求 |
|------|------|
| 模型类型 | 支持本地离线推理（ONNX/TensorFlow Lite），兼顾隐私与速度 |
| 分类种类 | ≥ 10 种常见场景类别 |
| 单张推理时间 | ≤ 200ms（GPU）/ ≤ 500ms（CPU） |
| 准确率 | Top-1 ≥ 85%，Top-3 ≥ 95% |
| 人脸检测 | 可选开启，用于"人物"分类细分 |

| FS-03 | 缩放与拖拽 | 支持双指捏合/鼠标滚轮缩放（25%~400%），缩放后可拖拽平移 | P0 |
| FS-04 | 图片信息面板 | 底部/侧边滑出信息栏：文件名、拍摄日期、尺寸、文件大小、分类标签、EXIF 数据 | P1 |
| FS-05 | 缩略图导航条 | 底部显示当前照片前后各 5 张的缩略图导航条，点击可快速跳转 | P1 |

### 3.5 在线预览

#### 3.5.1 功能描述

系统内嵌高性能图片查看器，支持**常见图片格式**的在线预览，无需下载即可查看高清原图。

| 编号 | 需求项 | 详细描述 | 优先级 |
|------|-------|---------|--------|

| OP-02 | 高清预览 | 点击缩略图后优先加载中等分辨率（1080p），支持手动加载原图 | P0 |
| OP-03 | 渐进式加载 | 大图先显示低分辨率模糊版，再渐进加载高清版本（类似 Medium 效果） | P1 |
| OP-04 | 懒加载 | 可视区域外的缩略图延迟加载，使用占位骨架屏 | P0 |

| OP-06 | 分享链接 | 支持生成带过期时间的临时分享链接，供外部访问预览（不暴露本地路径） | P2 |

#### 3.5.3 图片格式兼容矩阵

### 3.6 下载功能

#### 3.6.1 功能描述

支持单张或批量下载图片到本地设备，提供灵活的格式和尺寸选项。

#### 3.6.2 详细需求

| 编号 | 需求项 | 详细描述 | 优先级 |
|------|-------|---------|--------|
| DL-01 | 单张下载 | 全屏模式下点击下载按钮，直接下载当前照片原图 | P0 |
| DL-02 | 批量下载 | 选择多张照片后点击批量下载，系统打包为 ZIP 并提供下载 | P0 |
| DL-03 | 下载尺寸选择 | 下载前可选：原图、高清（1920px）、标清（1280px）、缩略图（480px） | P1 |
| DL-04 | 格式转换 | 下载时可选输出格式（JPEG / PNG / WebP / 原格式），支持质量调节 | P2 |
| DL-05 | 下载队列 | 批量下载显示进度队列，支持暂停/取消，后台执行不阻塞浏览 | P1 |
| DL-06 | 断点续传 | 大批量下载中断后可从断点恢复（浏览器环境受限于 blob 下载则提示重新开始） | P2 |
| DL-07 | 保留 EXIF | 下载的照片默认保留原始 EXIF 信息（拍摄参数、GPS 坐标等），用户可选择清除 | P2 |
| DL-08 | 下载历史 | 记录最近 50 条下载记录，支持一键重新下载 | P2 |

#### 3.6.3 下载流程

```
[选中照片（单张/批量）] → [点击下载]
    → [弹出下载选项面板：尺寸 / 格式 / 是否保留EXIF]
    → [确认下载] → [单张：浏览器触发下载]
                   → [批量：后台打包ZIP → 生成下载链接 → 自动触发下载]
    → [显示下载进度（批量时）] → [完成提示]
```

### 4.2 响应式设计

| 屏幕宽度 | 布局策略 |

| 1024-1439px（平板横屏） | 侧边栏可折叠，缩略图 4 列 |

### 4.3 主题方案

- **浅色主题**：白色背景 (#FAFAFA)，深色文字，图片卡片浅灰阴影
- **深色主题**：深灰背景 (#1A1A1A)，浅色文字，图片卡片深色边框
- 跟随系统主题设置，支持手动切换

## 6. 非功能需求

### 6.1 性能指标

| 指标 | 目标值 | 测量方法 |
|------|-------|---------|
| 首屏加载时间 | ≤ 2 秒 | Lighthouse Performance Score |
| 1000 张缩略图渲染 | ≤ 1.5 秒 | Chrome DevTools Performance 面板 |
| 全屏翻页延迟 | ≤ 200ms | 从输入到画面更新 |
| 大图加载（10MB 原图） | ≤ 3 秒 | 千兆网络环境 |
| 搜索响应时间 | ≤ 500ms | 1 万张图片库，关键词搜索 |
| AI 单张分类 | ≤ 200ms | GPU 环境 |
| 内存占用（万张级） | ≤ 500MB | 浏览器任务管理器 |

### 6.2 安全性

| 需求项 | 描述 |
|-------|------|
| 路径隔离 | 前端无法获取文件系统绝对路径，所有文件访问通过 API 代理 |
| 分享链接 | 支持设置有效期（1h/24h/7d/永久）和访问密码 |
| 防暴力下载 | 单 IP 下载频率限制（60次/分钟） |
| 输入校验 | 所有搜索和筛选参数进行服务端二次校验，防止注入 |
| 日志审计 | 关键操作（下载、分享、删除）记录操作日志，保留 90 天 |

| Firefox | ≥ 90 |
| Safari | ≥ 15 |

### 6.4 可扩展性
