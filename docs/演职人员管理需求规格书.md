# 影视库演职人员管理模块

> 需求规格说明书（SRS）

---

## 1. 项目概述

### 1.1 项目背景

随着本地影视库影片数量持续增长，用户不仅需要管理影片本身，还需要系统化管理演职人员信息，支持通过演员、导演、编剧等人员维度进行影片检索和关联浏览。同时，为降低人工录入成本，系统需具备网络信息自动刮削能力，从公开数据源获取演职人员资料。

### 1.2 项目目标

建立一个完整的演职人员管理模块，实现：
- 影片与演职人员的双向关联检索
- 演职人员详情及合作关系的展示
- 通过网络自动刮削补充人员信息

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 演职人员 | 参与影视作品创作的自然人，包括演员、导演、编剧、制片人等 |
| 人物 | 同“演职人员”，指具体自然人个体 |
| 作品 | 影视库中的影片或剧集 |
| 关联关系 | 影片与人物之间的参与关系，包含角色/职位信息 |
| 刮削 | 从网络公开数据源自动获取和填充演职人员信息 |
| 合作人物 | 与某演职人员共同参与过作品的其他人 |

---

## 2. 用户角色

| 角色 | 描述 |
|------|------|
| 普通用户 | 浏览影片和演职人员信息，查看关联作品和合作关系 |
| 管理员 | 管理影片和演职人员数据，维护关联关系，触发网络刮削 |

## 3. 功能需求

### 3.1 演职人员管理

#### 3.1.1 添加演职人员

**描述**：在系统中新增一个演职人员档案。

**前置条件**：用户拥有管理员权限。

**基本流程**：
1. 用户进入“演职人员管理”页面
2. 点击“新增人员”按钮
3. 填写或刮削人员信息（姓名、性别、出生日期、出生地、国籍、职业类型、人物简介、头像等）
4. 点击“保存”按钮
5. 系统校验信息完整性，保存数据并提示成功

**字段说明**：

| 字段 | 必填 | 说明 |
|------|------|------|
| 姓名 | 是 | 人员真实姓名，用于展示和检索 |
| 英文名 | 否 | 英文别名，便于刮削匹配 |
| 性别 | 否 | 男/女/未知 |
| 出生日期 | 否 | 年月日 |
| 出生地 | 否 | 出生城市或地区 |
| 国籍/地区 | 否 | 所属国家或地区 |
| 职业类型 | 否 | 演员/导演/编剧/制片人/摄影/剪辑/美术/音乐/其他（可多选） |
| 人物简介 | 否 | 个人简介、生平介绍 |
| 头像 | 否 | 人物照片/头像（支持图片上传或刮削获取） |
| 别名/艺名 | 否 | 其他常用名，以逗号分隔 |
| 外部数据源ID | 否 | 刮削来源标识（如TMDB ID、IMDB ID等） |

#### 3.1.2 编辑演职人员信息

**描述**：修改已有演职人员的信息。

**前置条件**：
- 该演职人员已在系统中存在
- 用户拥有管理员权限

**基本流程**：
1. 用户进入演职人员详情页或列表页
2. 点击“编辑”按钮
3. 修改所需字段
4. 点击“保存”更新信息

#### 3.1.3 删除演职人员

**描述**：从系统中移除演职人员档案。

**前置条件**：用户拥有管理员权限。

**业务规则**：
- 删除演职人员时，系统应检测其是否关联了影片
- 如有关联，提示用户确认是否同时解除关联关系，或阻止删除
- 建议提供“软删除”机制，保留历史数据

#### 3.1.4 演职人员列表

**描述**：以列表/网格形式展示所有演职人员。

**功能点**：
- 支持按姓名搜索
- 支持按职业类型筛选（演员/导演/编剧等）
- 支持按姓名首字母/拼音排序
- 支持分页浏览
- 列表项显示：头像缩略图、姓名、职业类型、参与作品数量

### 3.2 网络信息刮削

#### 3.2.1 刮削源配置

**描述**：管理员可配置和管理网络信息刮削的数据源。

**支持的数据源**（可扩展）：

| 数据源 | 类型 | 提供数据 |
|--------|------|----------|
| TMDB (The Movie Database) | 电影数据库 | 人员资料、作品列表、头像、简介 |
| IMDb | 影视数据库 | 人员资料、作品列表、评分 |
| 豆瓣 | 中文影视社区 | 中文人员资料、作品、简介 |
| Bangumi | 中文ACG数据库 | 动画、剧集相关演职人员 |

**配置项**：
- 启用/禁用刮削源
- API 密钥管理（如需要）
- 刮削优先级排序
- 请求频率限制（防封）
- 代理设置（可选）

#### 3.2.2 手动触发刮削

**描述**：管理员在新增或编辑演职人员时，手动触发网络刮削。

**基本流程**：
1. 用户在编辑页面点击“从网络刮削信息”按钮
2. 系统根据已填写的姓名/英文名，向配置的刮削源发起搜索请求
3. 搜索完成后，展示候选匹配结果（头像、姓名、出生日期、代表作等）
4. 用户选择正确的人物条目
5. 系统拉取完整资料并自动填充到对应字段
6. 用户确认或修改后保存

**刮削字段映射**：

| 本地字段 | 典型数据源字段 | 说明 |
|----------|--------------|------|
| 姓名 | name / 中文名 | 优先中文名，英文名辅助 |
| 英文名 | original_name / name | 原始英文名称 |
| 性别 | gender | 映射为 0/1/2 |
| 出生日期 | birthday / birth_date | 统一为 YYYY-MM-DD 格式 |
| 出生地 | place_of_birth | 城市或地区 |
| 国籍 | 需推断或手动设置 | 部分数据源不直接提供 |
| 人物简介 | biography / 简介 | 优先中文简介 |
| 头像 | profile_path / 头像URL | 下载并保存到本地 |
| 别名 | also_known_as / 又名 | 合并为逗号分隔字符串 |
| 外部数据源ID | id | 保存用于后续增量更新 |

#### 3.2.3 自动刮削（影片导入时）

**描述**：在导入新影片或扫描影片时，自动刮削影片中未知的演职人员信息。

**基本流程**：
1. 系统识别影片的演职人员信息
2. 对于本地数据库中不存在的人员，自动触发刮削
3. 刮削完成后自动创建人员档案并建立关联
4. 刮削失败或匹配不确定时，标记为“待人工确认”

#### 3.2.4 增量更新

**描述**：对已有刮削记录的演职人员，定期同步最新信息。

**功能点**：
- 管理员可手动触发单个人员的“更新信息”操作
- 系统自动检查头像、简介、作品列表等是否有变化
- 仅更新用户未手动编辑过的字段（避免覆盖用户修改）
- 支持查看变更历史，用户可选择性接受更新

#### 3.2.5 刮削任务管理

**描述**：查看和管理刮削任务的执行状态。

**功能点**：
- 显示当前刮削队列和进度
- 查看刮削历史记录（成功/失败/已跳过）
- 失败任务支持重试
- 支持批量刮削（如：为所有缺少头像的人员发起刮削）

**刮削状态定义**：

| 状态 | 说明 |
|------|------|
| 待处理 | 已加入刮削队列，等待执行 |
| 刮削中 | 正在请求数据源获取信息 |
| 成功 | 信息已获取并填充 |
| 失败 | 请求异常或数据缺失，已记录错误 |
| 待确认 | 匹配到多个候选结果，需人工选择 |
| 已跳过 | 用户主动取消或该数据源无结果 |

### 3.3 影片-演职人员关联管理

#### 3.3.1 为影片关联演职人员

**描述**：在影片详情页中，为该影片添加参与的演职人员及其对应的角色/职位。

**前置条件**：
- 影片已在系统中存在
- 被关联的人员已在系统中存在（或支持快速新建/刮削创建）

**基本流程**：
1. 用户进入影片详情页
2. 找到“演职人员”区域，点击“添加人员”
3. 在搜索框中输入姓名搜索已有人员，或点击“新建人员”快速创建，或“从网络刮削”自动创建
4. 选择该人员在影片中的角色信息
5. 点击“确认”完成关联

**关联字段**：

| 字段 | 必填 | 说明 |
|------|------|------|
| 人员 | 是 | 关联的演职人员 |
| 职业类型 | 是 | 在该影片中担任的角色：演员/导演/编剧/制片人等 |
| 饰演角色 | 否 | 仅当职业类型为“演员”时填写，如“钢铁侠” |
| 角色类型 | 否 | 主演/配角/客串/特别出演（仅演员） |
| 排序权重 | 否 | 控制演员表中的显示顺序，数值越小越靠前 |

**业务规则**：
- 同一部影片中，同一个人只能关联一次（唯一约束：影片 + 人员）
- 一个人在同一部影片中可担任多个职位（如导演兼编剧），应通过多条关联记录实现

#### 3.3.2 修改关联关系

**描述**：修改某部影片中演职人员的角色/职位信息。

**前置条件**：该关联关系已存在。

#### 3.3.3 解除关联

**描述**：将某位演职人员从影片中移除。

**前置条件**：该关联关系已存在。

**交互方式**：在影片详情页的演职人员列表中，点击“移除”按钮，确认后解除关联。

### 3.4 演职人员信息展示

#### 3.4.1 演职人员详情页

**描述**：展示单个演职人员的完整信息，包括基本资料、影视作品、合作人物等。

**页面布局**：

```
┌──────────────────────────────────────────────────────┐
│  [头像]                                              │
│  姓名 / 英文名                                       │
│  [职业标签：演员] [职业标签：导演]                     │
│  出生日期 / 出生地 / 国籍                            │
│  ────────────────────────────────────────────────   │
│  人物简介                                            │
│  ────────────────────────────────────────────────   │
│  合作人物（按合作次数排序）                            │
│  ┌──────┐ ┌──────┐ ┌──────┐ ...                     │
│  │头像  │ │头像  │ │头像  │                          │
│  │姓名  │ │姓名  │ │姓名  │                          │
│  └──────┘ └──────┘ └──────┘                          │
│  ────────────────────────────────────────────────   │
│  影视作品                                            │
│  [演员(49)] [导演(8)] [编剧(7)] [制片人(7)] ...     │
│  ┌────────┐ ┌────────┐ ┌────────┐ ...               │
│  │海报    │ │海报    │ │海报    │                    │
│  │片名    │ │片名    │ │片名    │                    │
│  │年份·职位│ │年份·职位│ │年份·职位│                    │
│  └────────┘ └────────┘ └────────┘                    │
└──────────────────────────────────────────────────────┘
```

**展示字段**：

| 区域 | 展示内容 | 交互 |
|------|----------|------|
| 基本信息区 | 头像（大图）、姓名、英文名、职业标签（如演员、导演）、出生日期、出生地、国籍 | 点击职业标签可筛选作品 |
| 简介区 | 人物简介，支持展开/收起（超过5行时） | — |
| 合作人物区 | 横向滚动展示合作过的人物头像和姓名，按合作次数降序排列 | 点击跳转至该人物详情页 |
| 影视作品区 | 按职业类型分Tab页展示，每个Tab显示该职业下的作品列表 | 点击作品跳转至影片详情页 |

**合作人物计算规则**：
- 与该演职人员共同参与过至少1部作品的其他人员
- 按合作作品数量降序排列，合作次数相同则按姓名排序
- 展示Top 20，超出部分可点击“查看更多”展开

#### 3.4.2 演职人员影视作品列表

**描述**：在演职人员详情页中，按职业分类展示其参与的全部影视作品。

**展示方式**：

1. **按职业分类Tab**：
   - 演员、导演、编剧、制片人、活动、剪辑师等
   - 每个Tab显示该职业类型下的作品数量，如 `演员(49)`
   - 默认展示最频繁的职业类型（如演员）

2. **作品列表（列表视图）**：
   - 按上映年份降序排列（最新在前）
   - 每行显示：年份、影片名称、在该片中的角色/职位
   - 示例：`2024  无名  · 作为Mr. Tang`
   - 示例：`2023  热烈  · 作为导演 / 编剧`

3. **作品网格（网格视图）**：
   - 按上映年份倒序排列
   - 每个作品显示：海报缩略图、影片名称、上映年份、在该片中的职位/角色
   - 点击作品跳转至该影片详情页

### 3.5 双向浏览功能

#### 3.5.1 在影片详情中查看演职人员

**描述**：在影片详情页中展示该影片的全部演职人员信息。

**展示内容**：
- 按职业分组展示（导演、编剧、主演、配角等）
- 演员组按角色类型/主演顺序排列，主演在前
- 每个人员显示：头像、姓名、饰演角色/职位
- 点击人员可跳转到该人员详情页
- 悬停人员可显示简要信息卡片（头像、姓名、代表作）

**界面示意**：
```
影片：《无名》
├── 导演
│   └── 程耳
├── 编剧
│   └── 程耳
├── 主演
│   ├── 梁朝伟 饰 何先生
│   ├── 王一博 饰 叶先生
│   └── 周迅 饰 陈小姐
└── 配角
    ├── 大鹏 饰 唐部长
    └── 王传君 饰 王先生
```

#### 3.5.2 在演职人员详情中查看作品

**描述**：在演职人员详情页中展示该人员参与的全部作品。

**展示内容**：
- 按职业分类Tab展示
- 每个分类下按上映年份倒序排列
- 每个作品显示：海报缩略图、影片名称、上映年份、在该片中的职位/角色
- 点击作品可跳转到该影片详情页
- 显示参与作品总数

#### 3.5.3 全局搜索

**描述**：支持在全局搜索框中同时检索影片和演职人员。

**功能点**：
- 输入关键词后，同时展示匹配的影片和人员
- 匹配的影片按名称匹配度排序
- 匹配的人员按姓名匹配度排序
- 支持切换筛选范围（全部/影片/人员）
- 搜索结果中人员条目显示：头像、姓名、职业类型、代表作

### 3.6 数据展示增强

#### 3.6.1 人员合作网络

**描述**：在演职人员详情页中，展示与该人员合作过的其他演职人员。

**展示方式**：
- 列表形式：头像 + 姓名 + 合作作品数量 + 合作作品名称（最近3部）
- 按合作次数降序排列
- 点击合作人物跳转至其详情页

#### 3.6.2 统计看板

**描述**：展示演职人员相关的统计数据。

**统计项**：
- 总演职人员数量
- 各职业类型人数分布
- 已刮削/未刮削人员占比
- 作品平均参演人数
- 参演作品最多的人员排名
- 最常合作的演员/导演组合

## 4. 数据模型

### 4.1 演职人员表（`person`）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | UUID | 主键 |
| `name` | VARCHAR(100) | 姓名（必填） |
| `english_name` | VARCHAR(200) | 英文名 |
| `gender` | TINYINT | 性别：0-未知，1-男，2-女 |
| `birth_date` | DATE | 出生日期 |
| `birth_place` | VARCHAR(200) | 出生地/城市 |
| `nationality` | VARCHAR(100) | 国籍/地区 |
| `occupation` | JSON | 职业类型数组 |
| `biography` | TEXT | 人物简介 |
| `avatar_url` | VARCHAR(500) | 头像URL/本地路径 |
| `aliases` | VARCHAR(500) | 别名，逗号分隔 |
| `scraped` | BOOLEAN | 是否已通过刮削获取过信息 |
| `scraped_at` | DATETIME | 上次刮削时间 |
| `tmdb_id` | VARCHAR(50) | TMDB 外部ID |
| `imdb_id` | VARCHAR(50) | IMDb 外部ID |
| `douban_id` | VARCHAR(50) | 豆瓣外部ID |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 更新时间 |
| `deleted_at` | DATETIME | 软删除时间 |

### 4.2 影片表（`movie`）- 仅列出相关字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | UUID | 主键 |
| `title` | VARCHAR(200) | 影片名称 |
| `release_year` | INT | 上映年份 |
| `poster_url` | VARCHAR(500) | 海报URL |
| ... | ... | 其他影片字段 |

### 4.3 影片演职人员关联表（`movie_person`）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | UUID | 主键 |
| `movie_id` | UUID | 影片ID（外键） |
| `person_id` | UUID | 人员ID（外键） |
| `occupation` | VARCHAR(50) | 在该片中的职业类型 |
| `character_name` | VARCHAR(200) | 饰演角色名（仅演员） |
| `role_type` | VARCHAR(20) | 角色类型：主演/配角/客串/特别出演（仅演员） |
| `sort_order` | INT | 排序权重，数值越小越靠前 |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 更新时间 |

**索引建议**：
- (`movie_id`) — 用于查询影片的演职人员
- (`person_id`) — 用于查询人员的作品
- (`movie_id`, `person_id`) — 唯一索引，防止重复关联
- (`person_id`, `occupation`) — 用于按职业类型查询人员作品

### 4.4 刮削任务表（`scraping_task`）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | UUID | 主键 |
| `person_id` | UUID | 关联的人员ID（可为空，表示批量任务） |
| `source` | VARCHAR(50) | 刮削数据源，如 `tmdb`、`imdb`、`douban` |
| `status` | VARCHAR(20) | 任务状态：pending / running / success / failed / skipped |
| `query` | VARCHAR(200) | 查询关键词（姓名/英文名） |
| `external_id` | VARCHAR(50) | 匹配到的外部数据源ID |
| `result` | JSON | 刮削结果（原始数据） |
| `error_message` | TEXT | 失败时的错误信息 |
| `started_at` | DATETIME | 开始时间 |
| `completed_at` | DATETIME | 完成时间 |
| `created_at` | DATETIME | 创建时间 |

### 4.5 合作人物缓存表（`person_collaboration`）- 可选，用于性能优化

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | UUID | 主键 |

## 5. 界面设计要点

### 5.1 影片详情页 - 演职人员区块

- **位置**：影片基本信息下方，剧情简介上方
- **按职业分组展示**：使用标签或分组标题区分（导演、编剧、主演、配角等）
- **人员展示形式**：头像 + 姓名 + 饰演角色/职位的卡片或列表形式
- **交互**：
  - 悬停人员头像显示简要信息卡片（头像、姓名、职业、代表作）
  - 点击人员跳转至其详情页
  - 管理员模式下显示“添加/编辑/移除”操作按钮
- **主演排列**：主演按 sort_order 排序，配角单独分组

### 5.2 演职人员详情页

- **顶部信息区**：
  - 左侧：大尺寸头像（支持点击查看原图）
  - 右侧：姓名（中英文）、职业标签（如：演员、导演）、出生日期、出生地、国籍
- **中间简介区**：人物简介，支持展开/收起
- **合作人物区**：横向头像列表，展示合作过的人物，按合作次数排序，点击跳转
- **下方影视作品区**：
  - 按职业类型分Tab页，如：演员(49)、导演(8)、编剧(7)等
  - 每个Tab支持列表视图和网格视图切换
  - 列表视图：年份、片名、角色/职位
  - 网格视图：海报缩略图、片名、年份、角色/职位
  - 点击作品跳转至影片详情页

### 5.3 演职人员列表页

- **布局**：网格视图（推荐）或列表视图切换
- **筛选器**：职业类型下拉筛选、搜索框、刮削状态筛选
- **排序**：按姓名、按作品数量、按新增时间
- **操作**：管理员可点击“批量刮削”按钮，为未刮削人员发起批量刮削任务

### 5.4 刮削管理界面

- **刮削配置页**：数据源列表、API密钥配置、优先级排序、请求频率限制
- **刮削任务队列**：显示当前队列、进度、历史记录
- **待确认列表**：匹配到多个候选结果的人员条目，供管理员人工选择

## 6. 非功能需求

### 6.1 性能需求

- 影片详情页加载时间 ≤ 2 秒（包含演职人员数据）
- 演职人员列表页支持 10,000+ 条数据的流畅加载和分页
- 全局搜索结果返回时间 ≤ 1.5 秒
- 合作人物查询 ≤ 1 秒（建议使用缓存表优化）
- 刮削任务队列支持并发执行，单个请求间隔 ≥ 1 秒（避免触发数据源限流）

### 6.2 数据完整性

- 删除影片时，自动删除或解除相关的演职人员关联记录
- 删除人员时，自动解除所有影片关联（或提示确认）
- 确保关联表无孤儿数据
- 刮削数据与用户手动编辑数据共存时，优先使用用户手动编辑的数据，避免覆盖

### 6.3 可用性

- 人物头像支持常见图片格式（JPEG、PNG、WebP）
- 头像上传大小限制 ≤ 5MB
- 支持头像裁剪或自动缩略图生成
- 刮削失败时应有明确的错误提示，支持重试
- 网络异常时，刮削任务可自动重试（最多3次）
- 刮削过程不阻塞页面操作，后台异步执行

### 6.4 扩展性

- 职业类型应支持动态配置，便于后续新增职业分类
- 刮削数据源应支持插件化扩展，便于新增其他数据源
- 人员数据应支持导入/导出（CSV/JSON）以便批量操作
- 合作人物缓存表支持定时重建或增量更新

### 6.5 安全性

- 刮削请求应使用配置的代理或遵循数据源API使用规范
- 存储的外部数据源ID不对外暴露
- API密钥等敏感配置加密存储
- 刮削数据仅用于本地展示，不用于商业用途，遵守数据源使用条款
