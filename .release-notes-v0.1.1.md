## What's New (2026-06-25 ~ 2026-06-30)

### Hardware Acceleration
- Auto-detect NVIDIA NVENC, Intel QSV, AMD AMF, and Linux VAAPI
- Configurable in System Options; wired through JIT and background transcode workers
- Platform-specific GPU detection with Linux cross-compile fix

### AI Subtitle & Lyric Proofreading
- LLM-powered proofreading after ASR/OCR (typos, homophones, missing chars, OCR noise)
- Inline edit dialogs with per-language tabs (subtitles) and LRC parsing (lyrics)
- Import `.vtt`, `.srt`, `.ass`, or `.lrc` to replace existing content
- Tesseract one-click install: portable 7-Zip, no admin required

### Music & Media UI
- Reusable poster/image picker with library-scoped scrape candidates
- Album, artist, and genre edit modals
- FLV native playback for compatible sources (skip JIT transcode)

### Security & Documents
- Encrypt derived assets (previews, covers, transcode outputs) when library static encryption is enabled
- Improved document preview pipeline: LibreOffice page export, PDF rasterization, cover generation
- Home stream quality caps and transcode settings from system options
