## What's New (2026-07-04 ~ 2026-08-07)

### Community Edition Rebuild
- Removed commercial-only modules (pretranscode, license, retirement, PowerPlayer6) and aligned the codebase with the open community edition
- Rebranded the product from Knox-Media to **Vauldy** across config, web UI, i18n locales, and build outputs
- 6-platform cross-compile release build (Windows / Linux / macOS × amd64 / arm64) with embedded web UI
- Desktop build CI workflow (`desktop-build.yml`)

### Unified Media Orchestration (Phase 1–5)
- Durable ingest pipeline: enqueue, claim, scoped startup locking, and crash recovery
- Immutable processing lifecycle with source identity and platform path rules
- Publication policy v2: capability-driven planning, dependency enforcement, generation superseding, and safe SQLite retry foundations
- Startup preflight, diagnostics, and self-repair for stale or orphaned plan dependencies
- Poster pre-capture during scan and poster retry on ingest stalls (fixes head-of-line starvation)
- Scan coordination: ingest progress surfaced during library scans, poster capture moved outside the scan transaction to reduce SQLite contention

### Task Manager
- Unified task control plane API with one normalized task projection
- New admin console: task overview with counts, drill-down details, and authoritative task actions
- Independent grouped task tabs with zero-count hiding
- Audited mutations and idempotent batch operations
- Progress-driven timeouts for long-running task types (subtitle, AI, keyframe, atrack)
- Media id and title shown in task manager lists and details
- Task alignment display: per-media current-generation alignment counts and display status synthesis

### Resource Scheduler
- Global resource scheduler governing all execution paths with capacity reservations and queue claims
- Explainable task admission decisions and frozen admission metadata
- Aging and library fairness, plus admin-managed scheduler policy revisions

### Encryption & Storage
- Resumable AES-CTR encryption sessions with checkpointed media encryption and staged-encryption resume
- Hash-encrypt artifacts outside the IMMEDIATE write lock; same-volume quarantine root validation
- Cross-volume plaintext quarantine copies refused; short reads and negative lengths rejected in EncryptRange

### Media & Files
- Configurable media extension maps (`scan.file_extensions`) wired into file-type detection for videos, audio, and documents
- Sample-hash plaintext identity with imohash for fast duplicate equality
- Portrait source resolution adaptation for JIT transcode
- Document preview conversion and full-text indexing tasks

### Bug Fixes
- Fixed `overview_failed` on community builds caused by a missing `pretranscode_task_meta` table reference
- Fixed dev debugger launch (cwd/config resolution) and web UI 404 from incorrect `web/dist` lookup
- Replaced polling monitor with FSWatcher; fixed scrape reset and poster retry
- Fixed task list 500s from run-now expiry stored in non-SQLite format
- Cancel tasks stuck on superseded plan runs; reopen linked ingest steps on reset
- Retain clean busy connections and discard ambiguous transaction connections in SQLite
- Tolerate community `transcode_task` rows without `started_at`
- Prevented startup disk read storms from media scanning
- Various build fixes: go.exe resolution when not on PATH, submodule-internal changes no longer block release builds
